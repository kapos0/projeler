# Meal Planner Application: Lezizo
#### Video Demo:  https://www.youtube.com/watch?v=HCeuN7Pi0ec
#### Description: 

Lezizo is an innovative meal planning app designed to help users discover recipes based on ingredients they have at home. This user-centric app offers a great experience for booking favorite recipes and creating menus by allowing you to create a personal account.

Technologies Used

    Frontend: Built with React, enabling a dynamic and interactive user interface that allows for seamless navigation and user engagement.

    Backend: Developed using Python FastAPI, which ensures high performance and automatic generation of API documentation via swagger. FastAPI is ideal for crafting web APIs due to its speed and ease of use.

    Database: Employs MySQL for data management, where user accounts, favorite recipes, and ingredient information are securely stored.

Key Features

    Ingredient-Based Recipe Search: Users can enter their available ingredients, and Lezizo will suggest recipes they can prepare. This feature promotes efficient cooking and reduces food waste.

    Favorites: Users can bookmark their favorite recipes, allowing for quick and easy access to them later. This is especially useful for repeatedly enjoyed dishes.

    Menu creation: Users can create their own menu consisting of three meals.

    User Accounts: Users can create accounts to save their preferences and favorite recipes, enhancing the overall user experience.

Application Flow

    User Registration/Login: Users create an account or log in to access personalized features and saved recipes.

    Ingredient Input: Users specify available ingredients. The app processes this information to filter and display relevant recipes.

    Recipe Display: Based on the input, Lezizo presents recipes with comprehensive details, including ingredients, preparation steps, and cooking times.

    Favoriting Recipes: Users can save recipes to their favorites, making it easy to revisit preferred dishes.

    Creating Menu: Users can crate menus based on their preferences.

    Account Management: Users can manage their profiles, including updating personal details and viewing saved recipes.

Conclusion

Lezizo effectively combines React for a smooth and engaging user interface with FastAPI for a robust backend, all while managing data efficiently with MySQL. This innovative solution empowers users to maximize the use of their ingredients, simplify meal planning, and enjoy a memorable cooking experience.
